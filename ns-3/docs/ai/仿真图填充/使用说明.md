## 修改、运行单张图

每张图都有一份同名Python脚本。打开对应`.py`，修改顶部的外观参数或末尾的`DATA`，保存后执行，例如：

```bash
cd /home/fgfxf/ndnSIM/ns-3/docs/ai/仿真图填充
python3.8 06_车速_圆圈.py
```

也可以从任意工作目录用脚本的绝对路径执行：

```bash
python3.8 /home/fgfxf/ndnSIM/ns-3/docs/ai/仿真图填充/12_请求速率_圆圈.py
```

输出始终保存在脚本旁，覆盖同名的PNG、SVG和PDF；随后刷新Markdown预览即可。
运行一份脚本只更新它对应的图片，不联动其他图，也不修改Markdown。
本目录整体或任意单个绘图脚本均可复制到其他目录运行；绘图数据已经内嵌，不需要原始实验数据、其他绘图脚本、ns-3、SUMO、PyTorch或模型。

运行环境需要Python、NumPy和Matplotlib。本机验收使用Python 3.8，NumPy 1.24.4、Matplotlib 3.7.5。
若目标机器缺少依赖，可在目标Python环境中安装`numpy matplotlib`。

## 常用外观参数

- `FIGSIZE`：画布宽、高，单位英寸；`FONT_FAMILY`、`FONT_SIZE`：字体与字号；`DPI`：PNG分辨率。
- `COLORS`、`HATCHES`：颜色与纹理。四策略的显示名为Naive NDN、VTDF、RTVTDF、TKAN-PDF，配色为灰、橙黄、绿、紫。
- 坐标参数名称见各脚本顶部：`X_LIM`、`Y_LIMS`等；设为`None`时由该脚本的默认规则计算。手动指定边界后，应检查完整柱高和误差线仍可见。
- 三维图还提供`Z_LIM`、`VIEW_ELEVATION`和`VIEW_AZIMUTH`。
- `DATA`保存实际绘图数值；`None`表示不可评价或空分箱，不能改成零。误差线为样本标准差（SD），不是置信区间。

默认使用Liberation Serif衬线字体，可改为本机已安装的Times New Roman等字体。
柱状图按等距类别排布：横坐标位置0、1、2……对应`DATA`中的实际刻度标签；设置横轴范围时注意二者的区别。
不同图片之间保留各自独立的数据副本；手工改一张图的数据不会同步修改另一张图的共有基准点。

## 数值来源和单位

本图集以`paper-figures-followup-20261026/figures-paper-20261026/`保存的数表为准，参考`paper-editable-20261028/`的样式和数据内嵌方式。
主体对比源于`quick-fixed-model-20261022`的264轮实验，每个场景/条件/策略2次运行；周期与状态、报文补充数据每点3次运行，推理计时每个模型5个独立进程。
`retrain-quick-20261021`仅作为相同三个固定模型的训练来源，未混入其旧版对比结果。
初始来源文件及摘要见[来源记录.json](来源记录.json)；该记录是生成时快照，手工修改绘图脚本后不会阻止运行或自动改写来源记录。

| 图 | 数据定义 |
|---|---|
| 01 | 固定模型在NoForward采样上的离线Top-1准确率，保留全部可评价样本和交接子集；周期20/40/80/160毫秒。不是在线兴趣满足率。 |
| 02 | 车辆→内容表`m_vehicleToCs`的车辆键数、内容→车辆表`m_csToVehicles`的内容名称键数；展示全网条目数的时间加权均值及同时峰值。不是内存字节数，当前实现没有直接名为NVT/NCT的类。 |
| 03 | 默认20毫秒周期，注册取启动窗`registration`，更新取测量窗`delta`；两类均为hello Data的完整NDN编码大小，以字节计。先按运行求平均，再汇总三个种子；不是MAC发送成本。 |
| 04 | CPU单线程、batch=1；纯模型forward和控制器计算分别展示进程内中位数/P95的跨进程均值及SD。每进程预热100次、计时1000次；排除加载、Gym等待及I/O。 |
| 05 | 基准条件的5秒时间分箱；Circle/Grid/Spider分别取原图固定种子23001/23009/23017，每个分箱只统计成功请求的RTT。 |
| 06–08 | 车辆速度设置15/30/50/60 km/h，固定10车、120秒内6000请求；设置值不是实际车速或速度变化区间。 |
| 09–11 | 消费者数量5/10/15/20辆，每车5请求/秒；全网请求量随车辆数同时增长。 |
| 12–14 | 全网请求速率12.5/25/50/75/100请求/秒，由1500/3000/6000/9000/12000首次请求除以120秒得到，固定10车；只换横轴标签，纵轴统计值不变。 |

九张对比图的四指标顺序一致：额外Data应用提交次数、成功请求平均RTT、兴趣包满足率、网络负载。
额外Data次数是应用显式额外提交，不等于全部链路副本或成功补救次数；网络负载是网络Face的NDN L3出站Interest/Data累计Mbit，包含控制量及排空期，不含LP/MAC。
RTT中心值沿用原图按成功请求数加权的定义，误差线为各次运行RTT均值的样本SD；所有指标的原中心值和SD均保留。
