# Period单双候选覆盖率与高移动性补测

记录日期：2026-11-17。

用户允许为圆圈与蜘蛛网少量补实验。本次先复核旧预测，再预先固定圆圈/蜘蛛网×20/40/80/160 ms共8轮高移动性压力采样，使用原模型离线推理；没有修改生产代码、模型或候选阈值。全部轮次和结果均保留，无按结果追加种子或调整参数的追跑。

## 1. 使用统一且与实现对应的指标

指标为**返回时跨RSU迁移样本的单双候选规则覆盖率**：

1. 在已有可评价记录中保留`label != source_rsu_id`的记录。label仍为Router回程时的协议服务RSU。
2. 对候选概率按当前控制器方式转为float32并归一化，按概率降序排序。
3. 始终选择第一名；若第一名减第二名的概率差不超过0.10，或第二名概率不低于0.10，则再选择第二名。float32差值后按double阈值比较，沿用现有代码，无调参。
4. 分母N为该轮迁移记录数；分子C为真实label属于所选一/二候选集合的记录数。覆盖率＝100×C/N。没有有效样本时应报告NA，不能写0%。

这是把保存的离线概率代入当前选择规则得到的覆盖率，不是无条件Top-2，也不是实际在线交付成功率。本次采样策略为NoForward，不冒称已经在神经转发策略下测得相同交付结果。

实现依据：[C++选择策略](../../contrib/vndn-nn-rd/model/vndn-rsu-forwarding-policy.cc)、[formal_training.selected_targets](../../contrib/vndn-nn-rd/ai-training/formal_training.py)与[在线控制器](../../scratch/vndn-circle-simulator/vndn-circle-tkan-gym.py)。

圆圈只有两个RSU，无条件Top-2必然包含全部类别；重复同样的Top-2统计不能解决100%的问题。当前单双候选规则在模型有信心时只选一个RSU，因此能体现长周期下错误地只选择源站的情况。

读取`paper-figures-followup-20261026`已有36份预测；10车、6000请求、最高速度30 km/h，种子84001/84002/84003。先计算各种子C/N，再取三个种子百分比均值。Spider为旧13 dBm配置。

| Period（ms） | 圆圈（%） | 方阵（%） | 蜘蛛网（%） |
| --- | ---: | ---: | ---: |
| 20 | 100.00 | 78.02 | 72.91 |
| 40 | 100.00 | 54.18 | 65.60 |
| 80 | 98.15 | 31.62 | 36.79 |
| 160 | 92.44 | 13.64 | 15.47 |

旧圆圈20/40 ms仍100%，80/160 ms开始下降；蜘蛛网逐档下降。这是旧批次在同一指标下的完整结果，不能只保留方阵无条件Top-2、同时把其他场景这一列称为相同指标。

此前方阵无条件Top-2覆盖率91.69/86.42/82.88/82.80%仍保留，它与本节单双候选规则覆盖率定义不同。若将它和本文件的新圆圈/蜘蛛网放在同一表中，必须逐列明确指标、速度、种子和无线配置的区别，不能用统一Accuracy标题掩盖差异。推荐优先报告同一口径和同一批次条件的结果。

## 3. 新补测的固定设计

| 参数 | 固定设置 |
| --- | --- |
| 场景/轮次 | 圆圈、蜘蛛网各20/40/80/160 ms，共8轮，每档每场景1个种子 |
| 车辆/速度 | 10辆，最高速度设置60 km/h，作为高移动性压力条件 |
| 请求与窗口 | 每轮6000个请求，测量窗[20,140)秒，排空至143.5秒 |
| 随机种子 | 全部85001，按场景四档配对；同场景请求计划、路网与路线摘要完全一致 |
| 模型/推理 | 原冻结TKAN-LSTM模型，离线推理；不训练或调整阈值 |
| 采样策略 | NoForward，保存真实hello历史与协议回程标签 |
| 超时 | RSU为2×Period，OBU邻居失效固定2000 ms |
| Spider功率 | 当前16.5 dBm配置；每轮7个RSU和10个OBU设备实际功率已核验 |
| 执行方式 | 复用现有二进制，JOBS=4，waf仅--run-no-build，不configure或编译 |

设计在查看新结果之前写入`data/experiments/period-candidate-pressure-20261117/plan/plan.json`。旧36轮仅用于发现候选指标；本节为另一组预先固定参数、保留全部结果的探索性补测，不混入旧三种子的均值。

## 4. 新压力测试结果

每格为本档单个种子的覆盖率，单位为%。

| Period（ms） | 圆圈 | 蜘蛛网 |
| --- | ---: | ---: |
| 20 | 96.10% | 36.06% |
| 40 | 92.77% | 30.50% |
| 80 | 87.30% | 26.18% |
| 160 | 71.43% | 24.57% |

对应的正确数/迁移样本数如下：

| Period（ms） | 圆圈 C/N | 蜘蛛网 C/N |
| --- | ---: | ---: |
| 20 | 74/77 | 269/746 |
| 40 | 77/83 | 240/787 |
| 80 | 55/63 | 194/741 |
| 160 | 25/35 | 72/293 |

最高速度是输入设置；圆圈实际时间加权均速约60.00 km/h，Spider约19.42 km/h，受路网/交通条件限制，不能称Spider全程实际60 km/h。各档实际均速一致，详细值留在验收run_metrics中。

两场景四档均严格下降。以真实Period数值而非等距档位拟合直线，仅作形状描述，圆圈R²＝0.9938，蜘蛛网R²＝0.7583；圆圈接近线性，蜘蛛网后段趋平。主表始终使用原始计数比率，没有用拟合值替换数据。圆圈末档71.43%低于用户设想的约80%，Spider整体更低，不能宣称完全满足预设数值范围。

## 5. 结果边界

这组实验能够显示在所测高移动性、既有模型和固定候选规则下，周期变化对应的候选覆盖变化；不能把不同速度或功率的旧新批次直接拼接。RSU超时随周期变化，真实标签也由hello关联驱动，尚未隔离这些共同变化的因果贡献。

每档仅1个种子，迁移子集较小，这是探索性结果，不是稳定均值或三场景统一的最终论文结论。保留所有数值；若160 ms低于期望的约80%，也不抬高、插值或更换种子。本次按预先设定的8轮结束，没有为得到指定90/80范围扩大搜索。
