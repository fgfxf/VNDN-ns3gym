## 手动再次重画

使用原项目Python3.8环境，指定一个新的空目录：

```bash
cd /home/fgfxf/ndnSIM/ns-3
python3.8 tools/experiments/replot_paper_figures.py \
  --root data/experiments/paper-figures-followup-20261026 \
  --output data/experiments/paper-figures-followup-20261026/figures-paper-rerun
```
