策略编号是：

| 编号 | 策略 |
|---|---|
| 0 | NoForward，无补救 |
| 1 | VTDF |
| 2 | RealTimeVTDF |
| 3 | 神经网络策略 |

跑神经网络时，把 `--strategy 0` 换成 `--strategy 3`，再加：

```bash

```

这个入口会**自动启动 Python 推理控制器和 C++ 仿真**，不用再开两个窗口配合。模型路径要换成真实文件，三个场景要使用各自的模型。
