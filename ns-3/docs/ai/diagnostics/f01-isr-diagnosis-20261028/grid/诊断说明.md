## TKAN-PDF定位结果

| 两seed合计 | 1500档 | 12000档 |
|---|---:|---:|
| GENERATED且OBU Interest OUT | 3000 | 24000 |
| 有RSU上行Interest OUT的唯一请求 | 2812 | 22417 |
| 有服务器Data OUT | 2812 | 22417 |
| 有任意RSU完整Data RX | 2812 | 22417 |
| 有RSU无线Data OUT | 2812 | 22417 |
| 有目标OBU完整Data RX | 2763 | 19981 |
| 应用按期满足 | 2763 | 19981 |
| ISR | 92.1000% | 83.2542% |

- 未观察RSU上行Interest：188/3000=6.2667% → 1583/24000=6.5958%，仅增加0.3292个百分点。
- 已有RSU无线Data出站、但无目标OBU完整Data入口：49/3000=1.6333% → 2436/24000=10.1500%，增加8.5167个百分点。
- 上述两项解释ISR总下降8.8458个百分点。**Grid并非不下降，下降主要发生在Data无线出口至目标车辆完整接收之间。**
- 以已有无线出站为分母，接收缺失率为49/2812=1.7425% → 2436/22417=10.8668%。这两个百分数与上一项分母不同，不能混用。
- 这是定位层次，不足以在MAC拥塞、分片丢失、预测站不可达等原因之间做因果分摊；旧数据没有所需MAC/RSSI和逐分片事件。
