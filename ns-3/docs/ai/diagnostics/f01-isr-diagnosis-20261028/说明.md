## 复算与恢复

原始数据仍在 `data/experiments/quick-fixed-model-20261022/`，本归档不能替代它、输入文件、模型及源快照的备份。脚本按原项目结构和路径读取保存文件，不能仅携带本目录就独立复算。

主文档提供工程目录中的复算命令。若清理了 build，可先恢复所有分析脚本，再执行这些命令：

```bash
cd /home/fgfxf/ndnSIM/ns-3
python3.8 - <<'PY'
from pathlib import Path
import shutil
source = Path('docs/ai/diagnostics/f01-isr-diagnosis-20261028')
target = Path('build/validation/f01-isr-diagnosis-20261028')
for script in source.rglob('*.py'):
    destination = target / script.relative_to(source)
    destination.parent.mkdir(parents=True, exist_ok=True)
    shutil.copy2(script, destination)
PY
```

请在恢复后的 build 目录运行 Circle 脚本：它们向脚本所在目录写派生文件；不要直接在归档目录运行并覆盖记录。Circle `verify_and_summarize.py` 必须在 `analyze.py` 完成后执行。地图脚本应按主文档指定 `--output`，避免写回档案。

这些程序只扫描已有数据，不启动 waf、SUMO、训练或仿真。脚本中的原路径及默认输出目录是有意保留的历史上下文；迁移到不同工程路径时，应显式适配路径并保留原档案。
